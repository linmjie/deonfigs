# My Configs
Intended to be used with gnu stow.
Use `stow <dir>` to place the config files in the right spots as symlinks to the configs inside of here,
e.g. `stow nvim tmux` creates a `~/.config/nvim` directory and `~/.tmux.conf` file.
Since stow uses the path of the parent directory, these configs should be placed in a directory directly inside your home directory.
